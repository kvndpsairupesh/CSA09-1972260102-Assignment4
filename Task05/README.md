Objective

To understand different event-handling styles and implement a currency converter.

Program

"Main.java" accepts an amount in INR, allows the user to select USD or EUR, and displays the converted amount.

Conversion Rates

- 1 INR = 0.012 USD
- 1 INR = 0.011 EUR

Execution

Run using Java. Enter the INR amount and select the target currency.

Concepts Covered

- Event-driven programming
- ActionListener
- Inner and anonymous classes
- Lambda expressions
- Input validation

Limitation

This is a console-based adaptation for OnlineGDB. It does not implement the four actual Swing listener versions, Enter-key event handling, or dialog boxes.

Result

The program successfully converts valid INR amounts into USD or EUR and rejects invalid amounts.
