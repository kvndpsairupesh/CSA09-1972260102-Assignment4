Objective

To understand event handling, mouse clicks, point storage, and redrawing in a drawing pad application.

Program

"Main.java" stores entered X and Y coordinates in an ArrayList and displays the stored points and total click count.

Execution

Run the program using Java. Enter X and Y coordinates for each point. Enter "-1" at the X-coordinate prompt to finish.

Concepts Covered

- Mouse event handling ("mouseClicked")
- Point storage using ArrayList
- Redrawing using "paint(Graphics g)"
- Use of "@Override"
- Repainting after window restoration

Limitation

This is a console-based adaptation for OnlineGDB. It demonstrates coordinate storage and display but does not execute actual AWT mouse clicks or window minimisation and restoration.

Result

The program successfully stores coordinates and displays all stored points and the total count.
